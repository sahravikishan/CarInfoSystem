Implementation Tips

✅ Do's

  • Use CSS variables for all colors
  • Test color contrast (WCAG AA: 4.5:1 minimum)
  • Apply consistent spacing (8px grid)
  • Use Poppins for headings, Inter for body
  • Add smooth transitions (300ms) to interactions

❌ Don'ts

  • Don't use old colors (#4e4e4e, #000080, #dcdcdc)
  • Don't mix serif and sans-serif fonts
  • Don't add borders without soft gray (#E8E6E1)
  • Don't remove hover effects
  • Don't use bright pure colors (#FF0000, #0000FF)
